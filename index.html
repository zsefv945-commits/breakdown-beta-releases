Windows x64 Public Beta

“‘이거 해줘’를,
누가 무엇을 언제 할지로 바꿉니다.”

애매한 업무지시를 실행 가능한 업무 초안으로 정리하고, 모르는 담당자·기한·산출물은 임의로 채우지 않고 다시 확인합니다.

Windows Beta 다운로드 Release 보기

파일: BreakDown_BETA_001.zip · Node.js, Git, Docker 별도 설치 불필요

BreakDown의 현재 역할

  1. 모호한 업무지시 입력
  2. 회사 맥락 참고
  3. 업무 초안 생성
  4. 누가 / 무엇 / 언제 구조화
  5. 모르는 정보는 UNKNOWN으로 확인
  6. 사용자가 수정
  7. 사용자가 최종 확정

실제 사용 예시

모호함을 숨기지 않고, 필요한 것을 다시 묻습니다.

원래 지시
“이번 주 안으로 거래처 자료 정리해서 보내줘.”
↓
BreakDown이 확인
  • 담당자: 근거가 없으면 UNKNOWN
  • 업무: 어떤 거래처의 어떤 자료인지 확인
  • 기한: “이번 주 안”의 정확한 시각 확인
  • 전달 대상: 누구에게 보내는지 확인
↓
