Windows x64 Public Beta

Turn vague work requests into clear tasks:
who does what, and by when.

BreakDown turns ambiguous work requests into editable task drafts. When key information is missing, it asks for clarification instead of inventing assignees, deadlines, or deliverables.

Download Windows Beta View Release

File: BreakDown_BETA_001.zip · No separate Node.js, Git, or Docker installation required.

What BreakDown currently does

  1. Accepts a vague work request
  2. References available company context
  3. Creates an editable task draft
  4. Structures who / what / when
  5. Leaves missing information unresolved and asks
  6. Lets the user edit the draft
  7. Lets the user confirm the final task

Example

It does not hide uncertainty. It asks for what is missing.

Original request
“Please organize the client materials and send them this week.”
↓
BreakDown should clarify
  • Owner: Who owns the task?
  • Scope: Which client materials are included?
  • Deadline: What is the exact deadline?
  • Recipient: Who should receive the result?
↓
User confirmation

BreakDown creates an editable draft from confirmed information and keeps unknown fields unresolved until the user confirms them.

Beta limitations

Current support

  • Windows x64 only
  • Beta software
  • Cloud AI OFF
  • No external task execution
  • No installer
  • No code signing
  • No automatic updates
  • No Mac, Linux, or mobile support
  • Application UI is currently Korean-first

Privacy & company information

Start with synthetic or de-identified data

For the initial public beta, use synthetic or de-identified work examples instead of real company secrets or sensitive personal information.

The current distribution runs with Cloud AI turned off, but that does not mean there is zero privacy or security risk. Review important inputs and outputs yourself.
